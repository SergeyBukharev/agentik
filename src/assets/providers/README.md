# Model provider marks

The model selector uses these unmodified SVGs to identify its provider options. Each mark belongs to its respective provider.

- `openai.svg` and `openai-white.svg` are the black and white Blossom files from the official download. [OpenAI brand guidelines and usage terms](https://openai.com/brand/#usage-terms) · [OpenAI logo package](https://cdn.openai.com/brand/openai-logos.zip)
- `deepseek.svg` is the colored `ICON.svg` from the official developer brand kit. [DeepSeek brand guidelines](https://github.com/deepseek-ai/awesome-deepseek-integration/blob/main/docs/_logo%20svg/guidelines.md) · [DeepSeek ICON.svg](https://github.com/deepseek-ai/awesome-deepseek-integration/blob/main/docs/_logo%20svg/ICON.svg)
