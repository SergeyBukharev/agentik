# Agentik B-demo

Самостоятельное демо работает по адресу [sergeybukharev.github.io/agentik/b-demo/](https://sergeybukharev.github.io/agentik/b-demo/). У него свои входная страница, сборка, кеш браузера и пространство данных.

## Сценарии

- В обзоре можно начать разговор с карточки задачи, выбрать помощника или открыть новый чат нажатием на маскота. На десктопе наведение на баннер запускает WebGL-волну. При системном уменьшении движения иллюстрация остаётся статичной.
- Поиск находит помощников и чаты. На десктопе его открывает `Ctrl+K` или `⌘K`. В чате можно прикрепить изображение или текстовый файл, сохранить или скопировать ответ.
- Когда гость начинает писать, интерфейс показывает срок хранения. При первой отправке можно создать аккаунт, войти или отправить тот же черновик гостем. Гостевой чат исчезает из истории через три дня после последнего сообщения. При входе сохранившиеся гостевые чаты переносятся в аккаунт.
- В этой сборке аккаунты, история и вложения хранятся в браузере. Код проверяется локально, а ответы демонстрируют сценарии без подключения моделей. После первого открытия приложение можно перезагрузить офлайн.

## Сборка

Установи зависимости из корня репозитория через `npm ci`. Для разработки запусти `npm run dev:b-demo` и открой путь `/agentik/b-demo/`. Команда `npm run build:b-demo` собирает статические файлы в `b-demo/dist/`. На GitHub Pages содержимое этой папки публикуется в `agentik/b-demo/`. Команда `npm run test:b-demo` запускает браузерные сценарии в Chromium и WebKit.

## Референсы

- Центральное поле ввода и карточки с задачами взяты как паттерн для старта разговора. [Orbix AI на Dribbble](https://dribbble.com/shots/27720775-Orbix-AI-Modern-AI-Assistant-Dashboard-Design-System)
- Подсказки предлагают конкретное действие, когда у человека ещё нет готового запроса. [Pinterest Assistant](https://newsroom.pinterest.com/news/pinterest-assistant-revolutionizing-the-way-you-shop-online/)
- Читаемый текст оставлен центральной частью переписки, ответы можно копировать и сохранять. Отклики пользователей использованы как качественный референс. [Обсуждение на Reddit](https://www.reddit.com/r/ChatGPT/comments/1t2vcf3/in_ai_chat_what_should_stay_text_and_what_should/)
- Иллюстрация ведёт в разговор, а крупный цветовой блок оформляет вход в приложение. [A Portfolio You Can Talk To](https://www.cssdesignawards.com/sites/a-portfolio-you-can-talk-to/50496/) и [Slight Twist](https://www.cssdesignawards.com/sites/slight-twist/47899/)

Иллюстрация создана встроенным ImageGen и сохранена в `public/mascot.webp`. Бриф описывал улыбающегося лаймового робота в виде виниловой клавиши, полупрозрачную сиреневую орбиту и коралловую звезду на прозрачном фоне. Основные цветовые переменные светлой и тёмной тем лежат в `src/styles.css`.
