# Анимации в Agentik

| Библиотека | Что проверялось | Применимость |
| --- | --- | --- |
| Motion Mini | Вход `motion/mini`, анимация CSS-свойств через Web Animations API и измеримый вклад в бандл. [Документация](https://motion.dev/docs/animate) · [GitHub](https://github.com/motiondivision/motion) | Подходит для короткой реакции на результат и появления экранов ошибок. Шесть ячеек объединяются CSS-переходом. |
| GSAP + @gsap/react | React-хук с уборкой анимаций и управление сложными временными шкалами. [Документация](https://gsap.com/resources/React/) · [GitHub](https://github.com/greensock/react) | Подходит для экрана с длинной последовательностью связанных сцен. Вход в Agentik состоит из нескольких коротких состояний. |
| React Spring | Пружинные значения, переходы и интеграция с React. [Документация](https://www.react-spring.dev/docs/getting-started) · [GitHub](https://github.com/pmndrs/react-spring) | Подходит для интерфейсов, где движение постоянно зависит от жеста или физической модели. |

Выбран **Motion Mini**. В production-сборке отдельный чанк весит 3,20 КБ gzip. Переходы состояний используют CSS, трансформации и прозрачность. Шейдеры вынесены в отдельный WebGL-модуль. Обсуждения разработчиков помогли сформировать список кандидатов. Технические свойства сверены по документации. При открытии поисковой выдачи Google браузер показал проверку трафика. Для проверки рекомендаций по производительности использован материал команды Google Web.dev. [Обсуждение на Reddit](https://www.reddit.com/r/reactjs/comments/1le4ixv/do_you_prefer_gsap_or_framermotion/) · [Google Web.dev](https://web.dev/articles/animations-guide)

## Что взято из референсов

- В приложенном видео шесть ячеек при отправке собираются в одну полоску, а итог различается текстом и цветом. В Agentik ввод остаётся одним полем для вставки, редактирования и клавиатуры. Для ошибки предусмотрены сообщение и повторный ввод.
- В локальном Tyter компонент `EmotionalReveal` поднимает символы с небольшим пружинящим движением со сдвигом по времени. Приветствие Agentik использует тот же ритм и цветовой блик на маске текста WebGL. Публичный экран показывает форму входа. [Tyter PRO](https://tyter.app/pro/)
- Короткая диктовка проявляется буквами прямо в поле сообщения по таймингам Serega Gentle. Для длинного фрагмента используется одно проявление. Распознанный текст сразу доступен для редактирования. У микрофона во время записи расходятся две CSS-волны, после отпускания они затухают. [Serega Gentle](https://github.com/mishanaer/deslop/tree/main/serega/serega-gentle)
- При ручном вводе за 180 мс проявляется только новый символ. Эффект использует прозрачность и короткий подъём по кривой Serega Gentle. Вставленный текст появляется сразу. [Serega Gentle](https://raw.githubusercontent.com/mishanaer/deslop/main/serega/serega-gentle/SKILL.md)
- Волна запускается от кнопки после первой отправки в профиле. На лендинге шейдер проходит по скелетону при ожидании медиа и проявляет иллюстрацию и карточки при загрузке. При отключённом WebGL есть CSS-переходы. С системной настройкой уменьшения движения интерфейс появляется без этих эффектов.
- Мобильная шторка, последовательность возврата, цели касания и отступы безопасных зон адаптированы к DOM по существующим референсам Agentik и Appllama. [Референс Appllama](https://github.com/Appllama/appllama-skills) · [Экраны Mobbin](research.md)
- В баннере на однотонной подложке расположен фирменный знак. При наведении или клавиатурном фокусе рядом со знаком появляются квадратные пиксели. Их цвет зависит от темы. При системном уменьшении движения пиксели появляются сразу и остаются на месте. [Цветовые токены](../design-system/colors.json)
- Нажатие на свободную область баннера запускает мягкий расходящийся блик. Он расширяется и затухает поверх иллюстрации. Нажатия на кнопки и режим уменьшения движения обходятся без волны.
