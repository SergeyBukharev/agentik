# Agentik в Telegram

Архив содержит готовый интерфейс в `dist/`, отдельный экран `dist/widget.html`, сервер `server.mjs` и материалы проекта в `docs/`. Для запуска нужен Node.js 24. Интерфейс, проверка кодов и просмотр общих копий работают с одного адреса.

## Запуск на компьютере

1. Распакуйте архив и откройте терминал в папке с `server.mjs`.
2. Скопируйте `.env.example` в `.env`. Сгенерируйте `AGENTIK_ACCESS_SECRET` командой `node -p "require('node:crypto').randomBytes(32).toString('hex')"` и запишите результат в `.env`.
3. Добавьте тестовый аккаунт в `AGENTIK_CLIENT_ACCOUNTS`. Чтобы выдать ему PRO в демо, внесите его код также в `AGENTIK_PRO_CODES`. Для списка кодов из файла укажите приватный путь в `AGENTIK_CODES_FILE`.
4. Запустите `node --env-file-if-exists=.env server.mjs`. Откройте [локальный вход](http://127.0.0.1:3001/agentik/#/login).

Пример формата для отдельной тестовой среды. Значение секрета сгенерируйте на сервере.

```dotenv
HOST=127.0.0.1
PORT=3001
ALLOWED_ORIGIN=http://127.0.0.1:3001
AGENTIK_CLIENT_ACCOUNTS=[{"email":"viewer@example.test","code":"7M4ZQ8"}]
AGENTIK_PRO_CODES=7M4ZQ8
TELEGRAM_BOT_USERNAME=your_agentik_bot
TELEGRAM_MINI_APP_SHORT_NAME=
TELEGRAM_SHARE_DIR=./data/telegram-shares
```

## Подключение бота

1. Запустите сервер на хостинге с постоянным диском и публичным HTTPS. Укажите `ALLOWED_ORIGIN` равным origin сайта без подпути. Если хостинг назначает порт и требует слушать сетевой интерфейс контейнера, используйте его `PORT` и `HOST=0.0.0.0`.
2. В `TELEGRAM_BOT_USERNAME` укажите имя своего бота без `@`. В [BotFather](https://t.me/BotFather) выберите бота и настройте **Main Mini App** на адрес `https://ваш-домен/agentik/`. Для именованного приложения укажите его short name в `TELEGRAM_MINI_APP_SHORT_NAME` и настройте тот же URL.
3. При необходимости добавьте кнопку меню рядом с полем чата через `/setmenubutton`. Проверьте запуск из профиля бота и из пересланной ссылки. [Настройка и способы запуска Mini Apps](https://core.telegram.org/bots/webapps#launching-the-main-mini-app)

Для публикации кнопки «Поделиться» достаточно имени бота. Код входа, файлы кодов и ключи моделей остаются в переменных окружения сервера. В Telegram открывается та же форма email и шестисимвольного кода. Тема и отступы учитывают интерфейс Telegram. Проверка через Telegram ID в этой сборке не используется.

## Как открывается виджет чата

1. В сохранённом личном чате или своей группе откройте «Поделиться в Telegram». Подтвердите создание копии и отправьте ссылку в нужный чат.
2. С публичным HTTPS-адресом в `ALLOWED_ORIGIN` сервер выдаёт ссылку вида `https://ваш-домен/agentik/share/идентификатор`. Её превью содержит логотип, название опубликованного чата и иконку. Кнопка на странице открывает компактную копию. Прямая ссылка `https://t.me/имя_бота?startapp=идентификатор&mode=compact` тоже открывает виджет внутри Telegram.
3. В копии доступны до 50 сообщений на момент публикации, имена авторов и отметки о вложениях. Файлы и последующие сообщения остаются в исходном чате.
4. Ссылка действует 24 часа и открывается у любого, кому она передана. Отзыв закрывает доступ к копии и серверному превью. При создании новой копии предыдущая ссылка перестаёт работать.

Штатная кнопка Telegram открывает выбор диалога для отправки ссылки. Компактная копия показывает материалы Agentik внутри Mini App. Встраивание Telegram Post Widget предназначено для уже опубликованных сообщений публичных групп и каналов. [Официальная кнопка «Поделиться»](https://core.telegram.org/widgets/share) · [Запуск Mini App по ссылке](https://core.telegram.org/bots/webapps#direct-link-mini-apps) · [Документация Post Widget](https://core.telegram.org/widgets/post)

## Проверка перед показом

- Проверьте вход тестовой парой, переход в историю и соединение через HTTPS.
- Проверьте тёмную и светлую темы, клавиатуру и кнопку «Назад» на iOS, Android и Telegram Desktop.
- Отправьте ссылки на личный чат и свою группу. Откройте их из другого аккаунта Telegram, затем отзовите одну ссылку и проверьте экран недоступности.
- Храните `TELEGRAM_SHARE_DIR` на диске вне раздаваемой папки. Срок в 24 часа ограничивает доступ по ссылке. Для пилота задайте правила удаления истёкших файлов и хранения резервных копий.
- Оплата в Mini App пока отключена. Для продажи цифрового доступа внутри Telegram предусмотрите Stars и тестовую проверку платежей. [Telegram Stars](https://core.telegram.org/bots/payments-stars)
