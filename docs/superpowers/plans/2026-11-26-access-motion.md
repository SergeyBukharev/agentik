# Вход и анимации Agentik

**Цель.** Открывать рабочие разделы по коду из файла Tyter, сохранить локальные сценарии и довести мобильные состояния до проверяемого результата.

**Архитектура.** Лендинг доступен без входа. Node API проверяет код и выдаёт подписанную сессию на 90 дней. Vite обслуживает тот же API в разработке и локальном превью. На GitHub Pages статическая оболочка обращается к отдельно размещённому API. Вкладки сохраняют выбранную сессию, а история и профили разделены по выданному ID. Подтверждённая сессия открывает сохранённые данные офлайн до истечения срока.

1. Вход. Проверить формат `[код][метка]` и строки с одним кодом, недействительный и истёкший токены, ограничения числа попыток, запрет выдачи файла и работу входа после восстановления сети. Сохранить существующие данные в их исходных ключах, поскольку для старых данных связь с кодом неизвестна.
2. Навигация и визуальные состояния. Форма с одним текстовым полем и шестью видимыми ячейками, публичный лендинг, нормальные и ошибочные маршруты, статический 404 для Pages. Motion Mini для формы и страниц ошибок, ограниченные по времени WebGL-эффекты для приветствия, первой отправки, скелетонов и иллюстрации. Учитывать reduced motion, отсутствие GPU, сбой загрузки и уход со страницы.
3. QA. Пройти сценарии в production build при ширине 320, 360, 390, 768 и на desktop, проверить длинные строки, вкладки, офлайн, неверный код, прямые ссылки, запрет повторного эффекта. Сравнение библиотек и фактические результаты сохранить в docs.
4. Скилл. Подготовить в репозитории переиспользуемый workflow нативного порта на основе явно выбранного GitHub-коммита. Проверить обнаружение и границы использования.
