# Agentik Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Build a local Russian AI assistant service and supporting business artifacts.
**Architecture:** React SPA with hash routes and local persistence; a separate authenticated AI proxy; optional Supabase collaboration with RLS and invitation RPCs.
**Tech Stack:** TypeScript, React, Vite, Radix Dialog, Supabase, Node, Vitest, Python artifact libraries.
**Spec:** ../specs/2026-11-26-agentik-design.md

## Global Constraints

- Work directly in D:\Agentik, as requested. No publication or paid calls.
- 30 assistants, 6 characters; BEM, Inter, Manrope; /agentik/ base.
- Explicit demo mode; no API secrets in browser; real collaboration requires Supabase.
- XLSX formulas and PDF with labeled hypotheses, not fabricated research.

## Review Focus

- Corrupted/blocked browser storage must not crash the app or silently claim saving.
- Failed AI requests must preserve input and allow retry without duplicate messages.
- Invitation IDs alone must never grant room access; RLS applies to reads and writes.
- Route changes during an AI request must not append a response to another conversation.
- Small screens and keyboard users must retain navigation and dialog access.
