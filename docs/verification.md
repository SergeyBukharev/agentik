# Проверки Agentik

26 ноября 2026 · production-сборка запущена локально

## Автоматические проверки

- `npm run check`. 39 тестов в 12 файлах. TypeScript и сборка Vite завершились успешно.
- Проверка кода Tyter, неверный формат, срок сессии, лимит попыток и проверка origin. Отклонение токена, которому больше 90 дней. Обновление сессии при позднем ответе для предыдущего токена.
- Изоляция профилей, восстановление сохранённых чатов, повреждённый или недоступный кеш, избранное, повтор запроса без дублей и запись позднего ответа в исходный разговор.
- Комнаты, вход по приглашению, срок действия ссылки и обмен между вкладками. Лимиты AI-пакета в байтах проверены на длинной кириллической истории. Ответы провайдера проверены через тестовый транспорт.
- Кеширование HTML и ресурсов одного поколения. Сборка содержит `404.html`.
- Скилл для нативного порта прошёл официальный валидатор.

## Chromium и WebKit

`npx playwright test` прошёл 14 запусков. 12 в Chromium и 2 в WebKit с профилем iPhone SE. В тестах используются синтетические коды.

- Выдача 90-дневной сессии, отказ на неверный код, восстановление после сбоя сети, выход в связанных вкладках и изоляция кабинетов по коду.
- После кеширования отключена сеть. Каталог и комнаты открылись после перезагрузки. AI предложил подключиться, демочат ответил офлайн. Без действующей сессии форма дождалась подключения и повторно приняла код.
- Лендинг, вход, каталог, длинные сообщения, модальное окно и 404 проверены на ширинах 320, 360, 390 и 768 CSS px. Страница и лента категорий уложились в ширину viewport. Дополнительно проверены переход назад и системное уменьшение движения.
- Отложена загрузка JS и изображения. В обоих случаях появился скелетон. Тесты подтвердили отрисовку WebGL у приветствия, первой отправки и проявления изображения. В отдельном тесте интерфейс работал при отключённом WebGL и сбое загрузки SVG.
- Проверены неверные пути, устаревшая ссылка на чат, создание комнаты, подключение второго профиля и доставка сообщения между вкладками.

На локальном превью отдельно получены HTTP 200 при входе по коду из настроенного приватного файла и подтверждении выданной сессии. Сам файл в клиентской сборке отсутствует. Для отдельного имени приватного файла внутри проекта проверено отклонение прямого запроса в Vite dev.

В финальной сборке начальный JS весит 109,73 КБ gzip, CSS 9,75 КБ, Motion Mini 3,20 КБ и WebGL 2,56 КБ. Сняты и просмотрены мобильные состояния лендинга, формы кода и 404.

Проверка мобильного режима выполнялась в эмуляции. Физический телефон, системная клавиатура, экранные дикторы и standalone-установка в проверку не вошли.

## Документы

- XLSX: 38 формул, отсутствие error cells в сохранённых XML, независимая проверка базовой арифметики: переменные $0,51/MAU, результат $170/месяц, безубыточность 7 639 MAU.
- Сравнение сценариев внизу XLSX - сохранённые снимки; активный расчёт обновляется формулами, снимки обновляются генератором.
- PDF: 5 страниц, кириллический текст извлечён обратно, все страницы отрендерены Poppler и визуально просмотрены.
- SVG: четыре самостоятельных анимированных файла и общий React-компонент; reduced motion предусмотрен в CSS.

## Среда

Браузерный мультиплеер использует хранилище одного браузера. Для разных устройств нужна серверная синхронизация. GitHub Pages и внешний HTTPS API требуют отдельного размещения. Сценарий настоящего AI проверен на тестовом транспорте без платных запросов.

## Чаты, PRO и визуальные состояния

- Форма входа принимает пару email–код из приватной конфигурации. Для текущего блока кода проверены отсутствие внешней обводки и отдельная подсветка активной ячейки.
- Публикация личного чата переносит сообщения в локальную группу. Сценарий с двумя профилями проверяет присоединение по ссылке, PNG, возврат в приватный режим, отзыв ссылки и сохранение истории владельца.
- Проверены ошибка пустого поля, выбор модели, paywall второго чата, сохранение RU/ENG, удержание клавиши и кнопки микрофона с тестовым API распознавания речи.
- Скелетон лендинга проверен при блокировке JS и при отдельной задержке SVG. Для медиа проверены маска по силуэту и два разных цвета загрузки. Реакция баннера проверена с эмуляцией CPU ×4 и на мобильном viewport.
- Stdio MCP проверен вызовами настоящего клиента. Разрешённый контракт читается, приватный файл конфигурации отвергается.
- Презентации PRD и продуктовой истории отрендерены и повторно импортированы. Числа для пилота обозначены как целевые гипотезы.

Физический телефон, диктовка с реальным микрофоном, платёж и работа с живыми моделями требуют отдельной среды.

## Вход и соглашение

- Дополнительный email для одного и того же аккаунта задаётся в локальной серверной конфигурации. Оба разрешённых адреса получают одинаковый идентификатор аккаунта. Посторонний адрес получает HTTP 401.
- Поле автоматически отправляет один запрос после шестого символа. Проверены вставка, ручной повтор после сбоя сети, переход к истории и возврат на запрошенный экран по прямой ссылке.
- Один элемент логотипа сохраняет координаты и идентичность узла между страницами. Его SVG совпадает с favicon. Замок открывается после подтверждения кода.
- Страница соглашения проверена на мобильной ширине. Пустой рисунок отвергается. Валидная подпись сохраняется после перезагрузки и удаляется из браузера по действию пользователя. Отдельно проверены ввод имени, изоляция локальных записей и отказ хранилища.

Итоговый `npm run check` прошёл 56 тестов и production-сборку. Покрыты 23 сценария Playwright. В полном прогоне один тест маски иллюстрации упёрся в таймаут. В повторном прогоне все 8 целевых сценариев прошли. Тест маски использовал системный режим уменьшения движения, а отрисовку WebGL покрывают отдельные тесты.

## Меню модели и производительность анимаций

- Production-сборка и 62 теста Vitest прошли. В общем Playwright-прогоне прошли 30 из 31 сценария. Сценарий группового вложения достиг таймаута ожидания предпросмотра. Предпросмотр появился в снимке после таймаута, а изолированный повтор всей проверки прошёл за 26,6 с.

- Проверены границы и пауза градиента PRO, реакция баннера при CPU ×4, отсутствие карточки «С чего начнём?», приветствие в каждом новом чате, одноразовая волна, размер её WebGL-буфера и плавный CSS-эффект при отказе WebGL. [Замеры и ограничения](performance-audit.md)
