# Проверки Agentik

Дата: 26.11.2026. Локальный frontend-прототип, не публичный production-релиз.

## Автоматические проверки

`npm run check`: 33 теста в 9 файлах, TypeScript и production-сборка. Проверяются:

- 30 помощников и 6 персонажей; поиск на русском, категории.
- Валидация сохранённого состояния, обработка недоступного хранилища.
- Сессия на 90 дней, продление при сохранении активности, изоляция профилей.
- Закрепление активного профиля за вкладкой, последовательные изменения из устаревших вкладок.
- Сохранение исходного повреждённого кеша без разрушительной перезаписи; восстановление валидных записей.
- Избранное, создание помощника, демочат и история.
- Повтор запроса без дублей; сохранение изменённого черновика; пустой черновик нового разговора; поздний ответ после смены маршрута.
- Комнаты, присоединение второго профиля, сообщения, отказ неучастнику и истёкшему приглашению, обновление приглашения.
- Ошибки сохранения внутри доступного модального контекста.
- Совместимость HTML и JS одного поколения в офлайн-кеше.
- Опциональный AI proxy: авторизация, origin, размер запроса, rate limit, ошибки провайдера и корректный ответ через подменённый сетевой транспорт. Платные запросы не выполнялись.

## Браузер

Проверена production-сборка в Chromium in-app browser, desktop и мобильный viewport 390×844:

- Главная, каталог, поиск и открытие помощника.
- Отправка запроса в деморежиме и появление разговора в истории.
- Мобильная нижняя навигация, профиль и создание другого профиля.
- Светлая/тёмная темы, шторки; отсутствие горизонтального переполнения страницы в просмотренном состоянии.
- Два профиля в двух вкладках: создание комнаты, приглашение, присоединение и сообщение, видимое в исходной вкладке.
- Сервер preview был остановлен; повторная загрузка каталога и открытие профиля продолжили работать из кеша service worker.

Мобильная проверка - эмуляция размера экрана. Физический телефон, системная клавиатура, VoiceOver/TalkBack, standalone-установка PWA и низкоскоростная сеть не проверялись. Не заявляется гарантированное время загрузки. В одной из проверенных сборок начальный JS около 104 КБ gzip; профиль и комнаты имеют отдельные чанки.

## Документы

- XLSX: 38 формул, отсутствие error cells в сохранённых XML, независимая проверка базовой арифметики: переменные $0,51/MAU, результат $170/месяц, безубыточность 7 639 MAU.
- Сравнение сценариев внизу XLSX - сохранённые снимки; активный расчёт обновляется формулами, снимки обновляются генератором.
- PDF: 5 страниц, кириллический текст извлечён обратно, все страницы отрендерены Poppler и визуально просмотрены.
- SVG: четыре самостоятельных анимированных файла и общий React-компонент; reduced motion предусмотрен в CSS.

## Независимая проверка кода

Ревью обнаружило ошибки изоляции вкладок, TTL реестра профилей, сохранения устаревшего состояния, восстановления повреждённых записей и смешивания поколений кеша. Каждая исправлена с регрессионной проверкой, предварительно показавшей сбой. Дополнительно исправлены безопасный выбор иконки, сохранение отредактированного черновика, обновление приглашения и доступное отображение ошибок формы.

## Границы

Нет настоящего многопользовательского сервера, внешней аналитики, платежей и проведённого исследования аудитории. PostgreSQL/Supabase отсутствовали в настроенной среде; SQL не запускался. GitHub Actions подготовлен, но не выполнялся на GitHub. Публичного push/deploy не было. Одновременная запись сообщений в localStorage не транзакционна; это ограничение локального прототипа, не схема production-мультиплеера.
