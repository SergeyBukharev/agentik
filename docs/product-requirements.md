# PRD Agentik

## Задача и аудитория

Agentik помогает выбрать помощника под конкретную задачу, начать с примера запроса и вернуться к истории. В первом пилоте проверяем семейный бюджет, работу с документами и выбор помощника в широком каталоге. Набираем самостоятельных специалистов, участников небольших команд и людей, которые ведут домашние расходы.

> Когда нужно быстро подготовить рабочий результат, я хочу начать с помощника, который понимает тип задачи и предлагает первый шаг, чтобы получить пригодный черновик и продолжить работу с того же места.

Для проверки каталога сохраняем задачи по брифу на логотип, баннер или презентацию и по продуктовым решениям о юнит-экономике, команде, проблемах пользователей или приоритетах бэклога. Для каждой узкой задачи задаём критерий результата до сессии. [Следующие гипотезы](next-hypotheses.md)

## Как появился прототип

1. В исходном брифе были каталог по типам задач, примеры запросов, персонажи, поиск и история. Это дало сценарий, который можно пройти с минимальным заданием.
2. Реализация показала этот сценарий в деморежиме. По запросу пользователя каталог и история получили приоритет в мобильном интерфейсе. Профили, сохранение истории и локальные комнаты позволили проверять поведение до подключения облачной инфраструктуры.
3. Следующий этап добавил вход по коду, сессии на 90 дней, офлайн-кеш и состояния загрузки. Проверки есть в локальном QA, достоверность продуктовых гипотез предстоит оценить отдельно.
4. Текущая итерация добавила семейный бюджет, доски документов и пробный лимит по принятым сообщениям. Отдельный комплект Telegram Mini App позволяет развернуть приложение и виджет для чтения копии личного или группового чата.

## Требования к выпуску

| Сценарий | Требование | Проверка |
| --- | --- | --- |
| Найти помощника | Категории, поиск, роли «Графический дизайнер-иллюстратор» и «Продакт-менеджер». Первые запросы показывают, какой результат можно получить. | Участник выбирает роль и отправляет подходящий запрос без подсказки модератора. Пользователь видит, где находится. |
| Начать и продолжить чат | История, приватность по умолчанию, выбор модели и черновик после ошибки. Вход по коду выдаёт сессию на 90 дней. После первого успешного входа и установки офлайн-кеша доступны каталог, сохранённые разговоры, демочат и локальные комнаты. | Проверить возврат через историю, повторный запуск офлайн, истечение сессии, ошибку API и недоступную модель. Очистка хранилища браузера требует повторного входа. |

Результат распознавания можно исправить перед отправкой. | Проверить удержание и отпускание, отмену, отказ в доступе к микрофону, ошибки распознавания, отсутствие поддержки API и удаление чернового вложения. |
| Вести семейный бюджет | В чате помощника «Семейный финансист» доступен раздел «Семейный бюджет». Общий месячный доход, обязательные платежи и покупки записываются в профиль. Приложение считает остаток и сумму на день. | Ввести доход, добавить и исправить расход. Проверить итог, смену месяца и сохранение записей после перезагрузки. |
| Работать с документами | Вкладка «Доска» в личном чате хранит файлы в браузере и извлекает текст из PDF с текстовым слоем, DOCX и заметок. Фрагменты можно перенести в редактируемый черновик для выжимки, сравнения или извлечения данных. Для скана доступен оригинал. OCR отсутствует. | Проверить поддерживаемый файл, предпросмотр, сохранение, скачивание оригинала и отправку после проверки черновика. Для PDF-скана проверить корректное состояние без извлечённого текста. |
| Позвать коллегу в локальную комнату | Создание группы, список участников и приглашение по ссылке действуют между профилями в одном браузере на одном адресе. Перевод в приватный режим отзывает приглашения и участие. | Проверить двумя локальными профилями. Обмен сообщениями между устройствами требует будущей облачной синхронизации. |
| Поделиться копией в Telegram | Из личного или группового чата отправитель формирует ссылку и открывает официальный выбор чата Telegram. Отправитель может её отозвать или выпустить новую. | Проверить открытую копию без входа в Agentik, отсутствие возможности ответить, сообщения с изображением, истечение срока и отзыв. Доступ к истории источника и вступление в группу управляются отдельно. |
| Оценить PRO | У аккаунта Free два пробных сообщения суммарно по личным и групповым чатам. Экран PRO открывается после второй принятой отправки. История доступна, повтор ответа сохраняет баланс. Демоаккаунт PRO получает право отправки через серверную настройку. Приём оплаты пока не запущен. | Проверить баланс 2 → 1 → 0, доставку второго сообщения, сохранение черновика при третьей попытке и отправку с выданным PRO. |

| Получить фирменные материалы | UI-кит, бренд-кит и пресс-кит доступны публично. У логотипа для светлого и тёмного фона можно скопировать SVG и скачать PNG в масштабе 1× или 2×. Палитра выгружается в JSON, пресс-кит содержит SVG-файлы и описание. | Проверить буфер обмена, скачивание, размеры PNG и переходы между наборами. |

## Каналы и границы выпуска

- Публичный GitHub Pages показывает лендинг и фирменные материалы. Рабочий демодоступ владельца ведёт в закрытое Sites-превью с проверкой доступа ChatGPT и входом Agentik. [Публичная страница](https://sergeybukharev.github.io/agentik/) · [Развёртывание](deployment.md)
- Telegram Mini App поставляется отдельным ZIP с веб-сборкой, Node API и инструкцией для HTTPS-развёртывания. Официальная кнопка `t.me/share/url` передаёт ссылку с `startapp` и `mode=compact`. Запуск на рабочем боте и в реальных клиентах Telegram предстоит подтвердить. [Инструкция к комплекту](telegram-mini-app.md) · [Sharing Button](https://core.telegram.org/widgets/share) · [Telegram Mini Apps](https://core.telegram.org/bots/webapps#direct-link-mini-apps)
- Снимок доступен по ссылке, пока она действительна. Доски, бюджет и комнаты хранятся в браузере. Сервер AI подключается отдельно. Для проверки совместной работы между устройствами нужна отдельная серверная реализация комнат с проверкой участников.
- Free и PRO доступны как сценарии пилота. Для будущей продажи цифрового доступа внутри Telegram платформа требует Telegram Stars (`XTR`). [Telegram Stars](https://core.telegram.org/bots/payments-stars)

## Гипотезы и критерии решения

Числа ниже — предлагаемые пороги принятия решений. Они не измерены. На качественных сессиях проверяем причины поведения. Доли фиксируем на отдельной пилотной когорте.

| Гипотеза | Эксперимент | Предлагаемый порог |
| --- | --- | --- |
| Специализация сокращает путь до пригодного черновика | Сравнить профильного помощника и пустой чат на сопоставимых задачах. Оценивать качество по общей шкале и менять порядок вариантов. | ≥70% пригодных черновиков среди попыток с помощником. Медианное время успешных пар ниже на ≥20% при сопоставимом качестве. |
| Семейный бюджет помогает планировать месяц | В тесте с модератором попросить внести доход и расходы, показать остаток на день и объяснить расчёт. | ≥70% участников, начавших задание, завершают его и правильно объясняют сумму на день. |
| История и рабочие инструменты дают повод вернуться | В течение семи дней наблюдать за пользователями с первым полезным результатом. Считать повтор задачи или содержательное продолжение. | D7 ≥30% среди участников с первым полезным результатом и полным окном наблюдения. |
| Копия чата помогает передать контекст в Telegram | Отдельно фиксировать создание копии, открытие выбора чата, загрузку виджета и результат у получателя. | ≥25% уникальных опубликованных ссылок открывает хотя бы один получатель за 24 часа. Загружаются ≥90% первых запусков по действующей ссылке. |
| После второй принятой отправки понятна ценность PRO | В исследовательском прототипе сравнить текущий экран с показом после третьей принятой отправки. Считать добровольные заявки на уведомление о PRO. | ≥10% увидевших экран после второй отправки оставляют заявку. Доля продолживших работу ниже контроля не более чем на 5 п.п. |

Основная метрика пилота — доля вошедших участников, которые завершили первую полезную задачу за 24 часа. Для черновика пригодность означает соответствие задаче, понятный следующий шаг и небольшие правки. Для бюджета критерий связан с расчётом, для доски — с работой над источником. Аналитика использует события и статусы без содержания чатов, документов и бюджета. [Определения и знаменатели](next-hypotheses.md)

## Исследование и приоритеты

1. Провести 8–10 интервью о недавних рабочих и бытовых задачах. Уточнить текущий способ работы, критерии результата и причину возвращения.
2. Провести 5–8 наблюдаемых мобильных сессий. Отдельно проверить вход, выбор помощника, получение первого результата, историю и поиск команды «Поделиться».
3. Запустить пилот бюджета, доски и каталога. Измерить активацию, время до результата и возврат. Проверить совместимость файлов и качество ответов на одинаковых задачах.
4. После развёртывания пилотного бота проверить виджет на реальных клиентах Telegram с парами отправитель–получатель. Перед запуском монетизации сверить интерес к PRO и стоимость успешной задачи. Совместную работу между устройствами оценить отдельно после появления серверных комнат.

## Условия изменения направления

- Если бюджет даёт устойчивый недельный возврат, выносим расчёт остатка и записи расходов в первый сценарий для этой аудитории.
- Если доска ускоряет подготовку пригодного результата при сопоставимом качестве, углубляем работу с источниками, заметками и повторными задачами.
- Если каталог помогает в нескольких типах задач, сохраняем широкую витрину. При слабом выборе проверяем вход через конкретные шаблоны и сокращаем количество ролей на первом экране.
- Если получатели читают копию и используют её для следующего шага, развиваем обмен результатом. Спрос на совместное редактирование проверяем по реальным приглашениям после запуска серверных комнат.
- Если экран PRO мешает повторению полезной задачи, проверяем другой момент показа или лимит ресурсоёмких операций.
